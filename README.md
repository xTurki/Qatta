## 📲 تثبيت التطبيق على الآيفون

> ما تحتاج حساب GitHub ولا أي شي ثاني. بس Safari.

**1. افتح الرابط في Safari**

اضغط زر **افتح التطبيق** فوق، أو انسخ الرابط هذا والصقه في Safari:

```
https://USERNAME.github.io/qatta/
```

> 💡 إذا انفتح الرابط داخل الواتساب أو تطبيق GitHub، اضغط **⋯** أو **🧭** واختر **فتح في Safari**. لازم يكون Safari، كروم ما يثبّت على الآيفون.

**2. اضغط زر المشاركة**

هو المربع اللي يطلع منه سهم لفوق **⬆️**:
- **أغلب الأجهزة:** تحت في منتصف الشاشة.
- **iOS 26:** اضغط **⋯** تحت على اليمين، وبعدين **مشاركة**.

**3. اختر «إضافة إلى الشاشة الرئيسية»**

انزل بالقائمة لتحت شوي لين تلقى **إضافة إلى الشاشة الرئيسية** ➕.

**4. اضغط «إضافة»**

إذا طلع لك خيار **فتح كتطبيق ويب**، خلّه مفعّل. وبعدها اضغط **إضافة** فوق.

**5. ✅ خلاص**

صار عندك أيقونة **القطّة** على الشاشة الرئيسية، تفتح بشاشة كاملة مثل أي تطبيق.

> ⚠️ افتح التطبيق دايماً من **الأيقونة**، مو من Safari. بيانات الأيقونة وبيانات Safari منفصلة عن بعض في الآيفون.

## 📌 نبذة

**القطّة** تطبيق ويب تقدّمي (PWA) يحل مشكلة متكررة في كل طلعة: *مين دفع كم؟ وكم على كل واحد؟ ومين يحوّل لمين؟*

تسجّل المشاركين وكم دفع كل واحد من حسابه، وبضغطة زر يحسب التطبيق قطّة كل عضو، ويوضح لكل شخص هل عليه مبلغ أو يرجع له باقي، ويقترح أبسط طريقة للتسوية. بعدها ترسل النتيجة مفصّلة لقروب الواتساب برسالة وحدة.

## ✨ المميزات

### إدارة الطلعات
- 📋 **قائمة الطلعات** كواجهة رئيسية، مرتبة بالتاريخ مع حالة كل طلعة (محسوبة / تحتاج إعادة حساب).
- ➕ **طلعة جديدة** بضغطة زر، مع اسم وتاريخ قابلين للتعديل.
- 🗂️ **أرشيف** للطلعات المنتهية، مع إمكانية إرجاعها في أي وقت.
- 🗑️ حذف الطلعة مع تأكيد.

### الأعضاء والمدفوعات
- 👥 إضافة الأعضاء واحد واحد، أو **عدة أسماء دفعة وحدة** مفصولة بفاصلة (أحمد، خالد، سعد).
- 💵 خانة لكل عضو بالمبلغ اللي دفعه من حسابه.
- 🔢 يقبل **الأرقام العربية والإنجليزية** (١٢٣ أو 123).
- 🎟️ **الضيوف:** أشخاص حاضرين لكن ما يدخلون في القطّة. وإذا دفع الضيف شيء، يرجع له كامل ويتوزع المبلغ على باقي الأعضاء.

### الحساب
- 🧮 **حساب القطّة** يجمع كل المدفوعات ويقسمها على الأعضاء (بدون الضيوف).
- ✏️ **تعديل وإعادة الحساب** بلا حدود. وإذا عدّلت بعد الحساب، ينبّهك التطبيق إن النتيجة قديمة.
- 🎯 **دقة بالهللة:** الحساب يتم بالهللات، فما تضيع هللة بالتقريب، ومجموع التحويلات يطابق المدفوعات بالضبط.

### طريقتين للتسوية
| الطريقة | كيف تشتغل |
|---|---|
| **تحويل مباشر** (الافتراضي) | كل واحد يحوّل مباشرة للي له فلوس، **بأقل عدد ممكن من التحويلات**. |
| **مدير القطّة** | الكل يحوّل لشخص واحد، وهو يرجّع للي لهم باقي. تقدر تحدد له **رقم جوال، ورقم حساب، وآيبان** (وحدة أو أكثر، أو تتركها فاضية). |

### المشاركة
- 📤 **مشاركة النتيجة** برسالة مرتبة ومفصّلة (واتساب، رسائل، أو أي تطبيق).
- 📋 زر **نسخ** لكل طريقة تحويل (الجوال / الحساب / الآيبان).

### عام
- 📱 يثبَّت على الشاشة الرئيسية ويفتح بشاشة كاملة مثل أي تطبيق.
- ✈️ **يشتغل بدون إنترنت** بعد أول فتح.
- 🌙 **وضع ليلي** تلقائي حسب إعدادات الجوال.
- 💾 **نسخة احتياطية واسترجاع** للبيانات كملف JSON.
- 🔒 **خصوصية كاملة:** كل البيانات محفوظة على جهازك فقط، وما تنرسل لأي خادم.

## 🧑‍💻 للمطوّر: نشر التطبيق على GitHub Pages

> هذا القسم لصاحب المشروع فقط، عشان يطلع رابط التطبيق أول مرة. المستخدم العادي يكفيه قسم **تثبيت التطبيق** فوق.
>
> تقدر تسوي الخطوات كلها من الآيفون.

1. سجّل دخولك في [github.com](https://github.com) (أو سوّ حساب جديد).
2. اضغط **＋ ← New repository**، سمّه `qatta`، واختر **Public**، ثم **Create repository**.
3. اضغط **uploading an existing file**.
   > 💡 من الآيفون: فعّل **طلب موقع سطح المكتب** من زر **ᴀA** في Safari عشان يظهر زر الرفع.
4. ارفع **الملفات** التالية مباشرة (مو داخل مجلد):

   ```
   index.html
   manifest.json
   sw.js
   icon-180.png
   icon-192.png
   icon-512.png
   README.md
   ```
5. اضغط **Commit changes**.
6. روح **Settings ← Pages**، واختر Branch: `main` والمجلد `/ (root)`، ثم **Save**.
7. بعد دقيقة أو دقيقتين يصير الرابط جاهز:

   ```
   https://<اسم-حسابك>.github.io/qatta/
   ```

### 2. التثبيت على الآيفون

1. افتح الرابط في **Safari** (لازم Safari، مو كروم).
2. اضغط زر المشاركة **⬆️**.
3. اختر **إضافة إلى الشاشة الرئيسية ← إضافة**.

تطلع أيقونة **القطّة** على الشاشة الرئيسية، وتفتح كتطبيق مستقل.

> **أندرويد:** افتح الرابط في Chrome ← القائمة ⋮ ← **تثبيت التطبيق**.

## 🧭 طريقة الاستخدام

1. من الواجهة الرئيسية اضغط **＋ طلعة جديدة**، واكتب اسم الطلعة.
2. أضف الأعضاء، واكتب قدام كل واحد **كم دفع من حسابه** (اتركها فاضية إذا ما دفع).
3. اضغط **ضيف** قدام أي شخص ما يدخل في القطّة.
4. *(اختياري)* فعّل **الكل يحوّل لمدير القطّة**، واختر المدير، وأضف طرق التحويل.
5. اضغط **حساب القطّة**.
6. اضغط **مشاركة النتيجة** وأرسلها للقروب.
7. بعد ما تخلص التسوية، اضغط **أرشفة الطلعة**.

## 🧮 طريقة الحساب

```
الإجمالي        = مجموع كل المدفوعات (الأعضاء + الضيوف)
قطّة كل عضو     = الإجمالي ÷ عدد الأعضاء (بدون الضيوف)
رصيد العضو      = اللي دفعه − قطّته
رصيد الضيف      = اللي دفعه كامل
```

- **رصيد موجب** ← يرجع له المبلغ.
- **رصيد سالب** ← عليه المبلغ.
- إذا ما انقسم الإجمالي بالتساوي، تتوزع **الهللات الزايدة** وحدة وحدة على الأعضاء، فيبقى المجموع مطابق 100%.

<details>
<summary><b>مثال عملي</b></summary>

<br>

| العضو | دفع | قطّته | النتيجة |
|---|---|---|---|
| أحمد | 300 | 150 | يرجع له 150 |
| خالد | 90 | 150 | عليه 60 |
| سعد | 0 | 150 | عليه 150 |
| ناصر *(ضيف)* | 60 | — | يرجع له 60 |
| **المجموع** | **450** | **450** | **0** |

**التحويل المباشر:**
1. سعد ← أحمد: 150
2. خالد ← ناصر: 60

</details>

## 🗂️ هيكل المشروع

```
qatta/
├── index.html      ← التطبيق كامل (الواجهة + المنطق + التصميم)
├── manifest.json   ← إعدادات التثبيت كتطبيق (الاسم، الأيقونة، الألوان)

├── icon-192.png    ← أيقونة أندرويد

```

**التقنيات:** HTML + CSS + JavaScript خام، بدون أي مكتبات أو أدوات بناء. البيانات محفوظة في `localStorage` على الجهاز.

## 🔄 التحديث

1. عدّل الملفات وارفعها على GitHub بنفس الأسماء (**Add file ← Upload files ← Commit**).
2. **مهم:** غيّر رقم النسخة في أول سطر من `sw.js`:
   ```js
   const CACHE = 'qatta-v5';   // ← زِد الرقم: qatta-v6
   ```
3. سكّر التطبيق في الآيفون وافتحه مرتين، ويتحدث تلقائياً.

> بياناتك المحفوظة ما تتأثر بالتحديث.

## 💾 البيانات والنسخ الاحتياطي

- كل الطلعات محفوظة **داخل الجهاز فقط**، ولا تُرسل لأي مكان.
- إذا حذفت التطبيق أو مسحت بيانات Safari، **تضيع البيانات**.
- من الواجهة الرئيسية اضغط **نسخة احتياطية** واحفظ الملف في تطبيق الملفات أو iCloud بين فترة وفترة.
- لاسترجاعها: **استرجاع نسخة** ← اختر الملف. الطلعات تندمج مع الموجودة بدون تكرار.
